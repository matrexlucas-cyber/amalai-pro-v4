# إدارة عملائي Pro — تطوير الواجهة

## محتويات المشروع
- `index.html`: التطبيق الحالي بعد تعديلات واجهة التذكيرات.
- التطبيق يعتمد على HTML/CSS/JavaScript وتخزين `localStorage`، ولا يحتوي هذا التسليم على مشروع Android/Capacitor أصلي.

## التشغيل
افتح `index.html` في متصفح حديث. للحصول على تجربة Android عبر WebView، يلزم إنشاء/ربط مشروع Android أو Capacitor منفصل، ثم اختبار الأذونات والإشعارات على جهاز حقيقي.

## ما تم تعديله في هذه النسخة
- إضافة زر إشعار تجريبي مع توضيح حالة إذن إشعارات الويب.
- إضافة تأجيل سريع للتذكير 15 دقيقة.
- إضافة تحقق يمنع السعر أو الدفعة السالبة عند حفظ الطلب.
- الحفاظ على الوظائف والبيانات الموجودة في ملف HTML الأصلي.

## قيود مهمة
إشعارات HTML/Web Notification ليست ضمانًا للتنبيه بعد إغلاق التطبيق أو قتل WebView. هذه النسخة لا تتضمن جدولة Android أصلية، WorkManager/AlarmManager، استقبال إعادة تشغيل الهاتف، أو Capacitor Local Notifications. لا تعتبر التذكيرات الخلفية مكتملة قبل إضافة طبقة Android واختبارها على أجهزة فعلية. لا يوجد APK ضمن هذا التسليم.

## بناء Android لاحقًا
1. أنشئ مشروع Capacitor أو Android WebView أصليًا.
2. أضف حزمة الإشعارات المحلية المتوافقة مع إصدار Capacitor المستخدم.
3. جدولة التذكيرات مع معالجة صلاحية الإشعارات والتنبيهات الدقيقة وإعادة التشغيل.
4. اختبر Android 13+ والأجهزة ذات قيود البطارية.
5. أنشئ APK من Android Studio أو GitHub Actions بعد ضبط Gradle وSDK.
